# Understanding Autism in the GIRAF Context

## What is Autism?

Autism Spectrum Disorder (ASD) is a neurodevelopmental condition characterized by differences in:
- Social communication and interaction
- Restricted or repetitive behaviors and interests
- Sensory processing

Autism is a **spectrum**, meaning it manifests differently in each individual. Some people need significant support in daily life, while others live independently with minimal assistance.

## Why Visual Support Tools?

Many individuals with autism benefit from visual supports because:

1. **Visual processing strengths**: Many people with autism process visual information more easily than verbal information
2. **Predictability**: Knowing what comes next reduces anxiety
3. **Independence**: Visual schedules allow children to follow routines without constant verbal reminders
4. **Reduced communication demands**: Pictures communicate without requiring social interaction

## GIRAF's Target Users

GIRAF apps are designed primarily for:

### Primary Users
- **Children with autism** (ages 5-12 approximately)
- **Varying support needs** - from minimal to significant assistance required
- **Danish institutional settings** - schools and care facilities

### Secondary Users
- **Caregivers and teachers** who create and manage schedules
- **Parents** who want consistency between home and school

## Key Design Principles for GIRAF

When working on GIRAF, keep these principles in mind:

### Simplicity
- Clean, uncluttered interfaces
- One action per screen when possible
- Clear visual hierarchy

### Predictability
- Consistent navigation patterns
- No unexpected popups or changes
- Clear feedback for actions

### Visual Clarity
- High contrast colors
- Simple, recognizable pictograms
- Adequate spacing between elements

### Flexibility
- Accommodate different ability levels
- Allow customization by caregivers
- Support both simple and complex schedules

## Common Terminology

| Term | Meaning |
|------|---------|
| **Pictogram** | A simple picture representing an activity, object, or concept |
| **Visual schedule** | A sequence of pictograms showing planned activities |
| **TEACCH** | A structured teaching approach using visual supports |
| **PCS** | Picture Communication Symbols - a common pictogram set |
| **AAC** | Augmentative and Alternative Communication |
