# Visual Schedules in GIRAF

## What are Visual Schedules?

A visual schedule is a series of pictures, symbols, or words that show the sequence of activities throughout a day or specific time period. They serve as a visual "to-do list" that helps users understand:
- What activity is happening now
- What comes next
- When an activity is finished

## Why Visual Schedules Help

### Reducing Anxiety
For children with autism, uncertainty can cause significant anxiety. Visual schedules provide:
- **Predictability**: Children know what to expect
- **Preparation time**: They can mentally prepare for transitions
- **Clear endings**: Activities have defined completion points

### Supporting Independence
Visual schedules reduce reliance on verbal instructions:
- Children can check the schedule themselves
- Reduces need for constant adult prompting
- Builds self-management skills

### Improving Transitions
Transitions between activities are often challenging. Visual schedules help by:
- Showing what comes after the current activity
- Providing warning of upcoming changes
- Making abstract time concepts concrete

## Types of Visual Schedules in GIRAF

### Day Schedules
A full day's activities displayed in sequence:
```
Morning routine → School → Lunch → Activities → Dinner → Evening routine
```

### Activity Schedules
Steps within a single activity:
```
Brushing teeth: Get toothbrush → Add toothpaste → Brush → Rinse → Done!
```

### Choice Boards
When a child can choose between activities:
```
Free time: [Reading] [Playing] [Drawing] [Music]
```

## GIRAF Implementation

### Pictograms
GIRAF uses pictograms (simple pictures) to represent activities. Key features:
- **Consistent style**: Same visual language throughout
- **Customizable**: Caregivers can add custom pictograms
- **Photos option**: Real photos can be used for personalization

### Schedule Management
Caregivers create and modify schedules through:
- Template schedules for recurring patterns
- Individual adjustments for specific days
- Activity library for quick schedule building

### Child Interface
The child-facing view emphasizes:
- Current activity prominently displayed
- Simple swipe/tap to mark activities complete
- Visual feedback when tasks are done
- Next activity preview

## Best Practices for Schedule Design

### Keep it Simple
- Start with fewer activities and add more as needed
- Use clear, unambiguous pictograms
- Avoid overloading with too much information

### Be Consistent
- Use the same pictogram for the same activity
- Maintain consistent schedule locations/times
- Keep the visual format stable

### Allow Flexibility
- Build in "buffer" activities
- Have backup plans visible when possible
- Allow for schedule modifications when needed

### Celebrate Completion
- Clear visual indication when activities are done
- Positive feedback for following the schedule
- Sense of accomplishment at day's end

## Research Background

Visual schedules are evidence-based practice, supported by:
- TEACCH methodology (Treatment and Education of Autistic and Communication related handicapped Children)
- Applied Behavior Analysis (ABA) research
- Special education best practices

Studies show visual schedules can:
- Reduce challenging behaviors
- Increase on-task behavior
- Improve independence
- Decrease transition times

## Common Challenges

### Over-reliance on Schedules
Some children may become too rigid about schedule adherence. Solutions:
- Introduce small, planned changes gradually
- Include "surprise" or "choice" blocks
- Practice flexibility in low-stress contexts

### Pictogram Confusion
When pictures aren't understood:
- Use photos of actual items/places
- Practice pictogram recognition separately
- Consider developmental level

### Schedule Abandonment
When schedules aren't used consistently:
- Train all caregivers on the system
- Make schedules easily accessible
- Review and update regularly
